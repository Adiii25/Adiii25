<a href="https://github.com/Adiii25/MeetMind-AI">
<img src="https://img.shields.io/badge/Repository-MeetMind--AI-181717?style=for-the-badge&logo=github"/>
</a>

**Python • FastAPI • Next.js • Whisper • Pyannote • ChromaDB • RAG • Docker**

An AI-powered meeting intelligence platform that transforms audio recordings into searchable, speaker-labelled conversations.

**Key Features:**
- Automatic speech recognition using OpenAI Whisper.
- Speaker diarization using Pyannote Audio.
- Transcript and speaker timestamp alignment.
- Multi-level vector indexing with ChromaDB.
- Retrieval-Augmented Generation for contextual meeting Q&A.
- Semantic retrieval with reranking and context selection.
- Streaming AI responses and persistent chat history.
- Transcript editing and downloadable outputs.
- REST APIs and WebSocket-based communication.

**Engineering Focus:** Speech processing pipelines, AI integration, vector search, RAG architecture and backend engineering.
